## 1. RAIBA 是什麼【RAIBA 事實】

| 項目 | 內容 |
|---|---|
| **全名** | Reconfigurable Array of Inexpensive Battery Architecture |
| **要解決的問題** | 固定串聯的系統裡，SOH 最差的那個模組會提前把整個 pack 或 rack 拖到 EOL |
| **2.0 架構主張** | 低頻拓樸重組（Enable/Bypass）＋ 選擇性雙向 DC/DC ＋ 確定性安全層 ＋ 電池數位孿生 |
| **控制分層** | µs 級硬體保護 → ms 級功率迴路 → 秒／分鐘級拓樸排程 → 小時級劣化最佳化 → 天級維護規劃 |
| **鐵律** | AI／最佳化器只能「提議」動作，硬安全迴路由確定性邏輯掌控 |
| **北極星指標** | Lifetime Safe Delivered Energy（全壽命安全交付能量）、System Availability over Lifetime（全壽命可用率） |
| **產品願景** | Long-Life Battery Chassis：機殼、電力電子、控制器壽命長，電池模組可替換 |
| **已有的電力電子成果** | dcdc4、hdc4、hdc8：多組新舊不一的電源各接 DC/DC 後串聯成 400–500 V 母線，每組出力可個別設定、切入切出不衝擊母線。目前只有 ngspice 模擬，還沒做硬體驗證 |

## 2. RAIBA 搬到 SOFC：哪些能直接用、哪些要改

### 2.1 可以直接搬的概念

1. **弱者綁架問題在 SOFC 更嚴重。**【假說，機理有文獻支持】
   - 串聯電堆中各電池流過同一個電流。劣化的電池電壓先掉，如果再遇到燃料分配不均，可能被推到反極。
   - 反極會讓 Ni 陽極再氧化，接著龜裂、密封失效、出現熱點，而且會往旁邊擴散。
   - 電池是「容量變小」，SOFC 則可能是「連鎖失效」。
2. **每個電堆或模組的電流可以個別控制，這是最強的手段。**【假說】
   - SOFC 的劣化速率跟電流密度、溫度高度相關。【外部，待查證定量關係】
   - RAIBA dcdc4／hdc 系列「每組出力個別設定、輸出串聯」的拓樸，可以改成「每個 SOFC 電堆群各自設電流」。
   - 這樣「降載保命」就能精準套用到弱的電堆。
3. **線上 EIS 有協同效應。**【假說】
   - RAIBA 歷史上就有 EIS、RC 模型、SOH 估測的工作。【RAIBA 事實】
   - DC/DC 本身可以注入小訊號擾動，邊發電邊做阻抗譜和 DRT 分析，用來分辨陽極、陰極、歐姆劣化。
   - 預測性維護（面向 2）可以直接建在這上面。
4. **控制分層與確定性安全層的原則完全適用。**

### 2.2 必須改寫的地方（SOFC 和電池的本質差異）

| 差異 | 影響 |
|---|---|
| **沒有 SOC，只有劣化** | 電池的 SOC 平衡、CC/CV 混充都不適用，最佳化目標變成「劣化速率平衡＋效率」 |
| **工作溫度 600–850°C** | Bypass（零電流）會讓電堆失去自身發熱而降溫，造成熱循環損傷，重新升溫要好幾個小時。所以 SOFC 的「Bypass」不是便宜的動作，要改成「熱待機」（低電流加還原氣氛） |
| **電、熱、流體三者耦合** | 電堆共用燃料歧管、重組器、空氣、尾氣再循環。光做電氣重組不夠，還要能做流體隔離，但高溫閥件又貴又難做 |
| **重組粒度** | 單電池無法 bypass（堆內是一體成形的串聯結構），最小可控單位是電堆或電堆群 |
| **時間尺度** | 熱時間常數是分鐘到小時，拓樸變更應該很少發生，並且受升降載速率限制 |
| **安全範圍** | 確定性安全層要從電氣擴展到**燃氣安全**（H₂／CO 洩漏、可燃氣體，對應 IEC 61511 SIL 等級） |

### 2.3 RAIBA 動作集合改成 SOFC 版本【假說】

| 電池版 RAIBA | SOFC 版 | 說明 |
|---|---|---|
| ENABLE | NORMAL | 正常發電 |
| DERATE | **DERATE**（主力） | 降電流密度，劣化速率下降 |
| REST／BYPASS | **HOT-IDLE** | 熱待機，避免熱循環 |
| ISOLATE | ISOLATE | 電氣＋燃料隔離，代價高，用於故障 |
| — | **HOT-SWAP** | 模組熱抽換，對應 Long-Life Chassis |
| — | **RECOVERY** | 部分劣化可逆，例如硫毒化可經處理恢復 |

## 3. RAIBA 怎麼跟三個面向連起來

### 3.1 成本：把 RAIBA 名字裡的「Inexpensive」借過來【假說】

- **放寬製造公差。** 允許電堆的一致性差一點，用分級（binning）加架構去吸收差異，降低 $/kW。需要量化製造良率與成本的關係。
- **超額配置在 SOFC 不是閒置成本，這是跟 RAID 最大的不同。**
  - 多裝 5–10% 的模組，所有電堆都能跑在比較低的電流密度。
  - 好處有三個：電壓變高所以**效率更高、燃料變省**；劣化變慢所以**電堆壽命變長**；同時多出 N+k 冗餘。
  - 所以會出現一個明確的最佳化軸：**資本支出 ↔ 燃料成本 ↔ 電堆更換成本**。這可能是對 LCOE 最有槓桿的設計變數。
- **電堆更換是 LCOE 的大項。** 如果壽命能從約 5 年延長到 7 年，影響很直接。【外部，待查證】

### 3.2 預測性維護：對應 RAIBA 的 Digital Twin 層

- SOFC 的劣化機理：Ni 粗化、陰極 Cr 毒化、硫毒化、積碳、分層、氧化還原循環。【外部】
- 量測：電堆電壓、電池群電壓分接、溫度場、線上 EIS／DRT。
- 從「預測」走到「行動」：預測結果直接驅動 DERATE 和維護排程。這正是 RAIBA 強調的 **Predict + Decide + Act**，不是只有 Predict。

### 3.3 韌性：RAIBA 架構本身

- 分層冗餘：電堆 → 模組 → 區塊（MW）→ 電廠（GW）。
- 故障隔離區要同時考慮電氣和燃料迴路的邊界。
- 北極星指標可以改寫成 **Lifetime Delivered kWh per Stack** 和 **Plant Availability**。【假說】

## 4. 規模數量級

假設【外部，典型值待查證】：單電池活性面積約 100 cm²、功率密度 0.3–0.5 W/cm²，每片約 30–50 W。

| 層級 | 單位功率 | 1 GW 所需數量 |
|---|---|---|
| 單電池 | 30–50 W | **約 2,000 萬～3,000 萬片** |
| 電堆 | 1–5 kW | 約 20 萬～100 萬個 |
| 模組 | 50–300 kW | 約 3,000～20,000 個 |

這已經是「資料中心機隊管理」的量級。電堆一年 1% 的失效率，就等於每年要換幾千個。
